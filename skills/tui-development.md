# TUI Development

Instructions for building terminal user interfaces with Mochi. Covers: ink (React for CLI), blessed, blessed-contrib, chalk, ora spinners, cli-table3, boxen, figlet, gradient-string. Includes patterns for: real-time dashboards, interactive menus, progress bars, colored output, terminal animations.
