Rust Core

Native performance core

Tokenization, budget math, compaction planning, and agent-loop decisions run in a zero-dependency Rust crate — with parity-tested TS fallbacks everywhere.

Autonomy

Daemon

Context

Token budgets, compaction, project memory, and intelligent retrieval across files, symbols, references, imports, and git history.

Safety

Observability

Install in 30 seconds.

Requires Node 22+ or Bun. Zero runtime dependencies.

# clone & build
git clone https://github.com/xanstomper/mochi.git && cd mochi
npm install && npm run build

# one-shot agent run
mochi "add a rate limiter to the auth service"

# persistent daemon
mochi daemon start --host 0.0.0.0
mochi daemon send "finish the auth flow"

# role-diverse agent team
mochi team "ship the payments refactor"

# replay any run end to end
mochi trace <goalId>
