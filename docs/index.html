What's inside

A complete harness, not a wrapper.

Mochi is built from scratch — no framework, no Electron, no runtime dependencies. The hot paths run in compiled Rust; everything else stays thin.

ENGINE

Compiled Rust core

Tokenization, budget math, compaction planning, and loop decisions execute natively via N-API. Every path has a parity-tested TypeScript fallback for cold installs.

ORCHESTRATION

Goals → DAGs → teams

Persistent goals decompose into task DAGs and run through role-diverse swarms with independent verifiers and an outcome judge before anything lands.

RUNTIME

Persistent daemon

One background process serves jobs, approvals, resume, and cron-scheduled agent runs over HTTP — drive it from scripts, editors, or CI.

CONTEXT

Adaptive context engine

Token budgets with compaction planning, project memory that survives sessions, and retrieval across files, symbols, references, and git history.

INTELLIGENCE

AST-native tooling

Tree-sitter codegraph over 15 languages: find callers, resolve type hierarchies, rewrite symbols without anchor drift, measure complexity.

SAFETY

Budgets & checkpoints

Token, cost, time, tool, model, and agent limits. Safe/ask/auto permissions. Git checkpoint and rollback under every destructive action.

OBSERVABILITY

Deep run traces

Every run is durable and replayable end-to-end, with deep redaction. Full-text session search across all history in SQLite+FTS5.

MODELS

Provider-agnostic

Any OpenAI-compatible endpoint, with capability routing (fast / coding / reasoning / review), budget-aware fallback, and multi-key rotation on 401/429/403.

LEARNING

Harness that learns

Project memory carries cross-session engineering facts; successful recovery strategies are recorded locally and reused on the next failure.
