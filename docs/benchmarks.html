Benchmarks

Standardized empirical comparison of Mochi (compiled Rust core + TypeScript TUI) against eight terminal agents: jcode, Claude Code, Cursor Agent, GitHub Copilot CLI, OpenCode, Codex CLI, Pi, and Antigravity CLI.

Methodology. Linux x86_64 (kernel 6.11, AMD Ryzen 9, 64 GB DDR5, NVMe PCIe 4.0). 10 independent launches per metric, Proportional Set Size (PSS) memory profiling, high-resolution PTY timing probes. A CI regression gate (npm run bench:memory) fails builds above memory ceilings so these wins can't silently regress. Full scripts: docs/BENCHMARKS.md.

Why the gap

DUAL-ENGINE

Compiled compute, not interpreted

Tokenization, budgeting, compaction math, indexing, and diffing run in zero-dependency Rust with in-process N-API memory sharing — no subprocess spawns on hot paths.

STARTUP

No synchronous probes

Zero blocking shell probes during initial frame generation. Lazy grammar/compiler loading cut imports from ~158 MB to ~61 MB.

RENDERING

No webview tax

Direct terminal ANSI rendering with optimized buffers. No Electron, no headless browser, no hidden UI process.
