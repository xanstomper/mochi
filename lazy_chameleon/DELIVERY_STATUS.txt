================================================================================
                         KEY INNOVATION
================================================================================

INFERENCE-TIME DISTILLATION
└─ Makes Flash reason like Opus without training

How It Works:
  1. Load pattern library (patterns extracted from teacher)
  2. Enrich user prompt with TEACHER_REASONING_PROMPT (1,200 words)
  3. Inject relevant patterns from library
  4. Optionally include live teacher CoT
  5. Send enriched prompt to student model (Flash)
  6. Student generates Opus-quality reasoning

Result: Flash outputs sophisticated reasoning instantly, no training needed!

Traditional ML:           Our Approach:
Days/weeks training ──→  Instant inference
Model fine-tuning ───→   Pattern injection
Deploy trained model ──→ Deploy with patterns
